# Development Roadmap

## Roadmap Overview

The Olympiad Portal project is broken down into three main phases (Sprints) to incrementally deliver value to the client, ensuring a structured progression from foundational infrastructure to advanced features.

## Sprint 1: Foundation & MVP (Current)

This initial sprint focused on establishing the groundwork for the project:
- **Repository Infrastructure:** Setting up the codebase structure and foundational configuration.
- **CI/CD Setup:** Implementing continuous integration and deployment pipelines.
- **UI/UX Design Systems:** Creating the core visual language and reusable component library.
- **Core Flows:** Building the Authentication and Organizer onboarding flows to secure the application and allow initial user registration.

## Sprint 2: Core Application Logic (Upcoming)

The next focus is building out the decoupled backend and connecting our frontend interfaces:
- **Decoupled API:** Developing the hand-written Express.js API to handle all business logic.
- **Database Integration:** Connecting the frontend forms to the PostgreSQL database for persistent data storage.
- **Educator Dashboard:** Implementing the dashboard for educators to access and download past papers.
- **Olympiad Management:** Building the "Create Olympiad" data mutations to allow organizers to manage events.

## Sprint 3: Advanced Features & Polish (Future)

The final sprint will focus on advanced functionality and system readiness:
- **Automated Marking:** Implementing automated multiple-choice marking for Olympiad submissions.
- **Analytics:** Developing school leaderboard analytics to track and display performance.
- **Final Polish:** Conducting final system testing, bug fixing, and optimization before the final project hand-in.
